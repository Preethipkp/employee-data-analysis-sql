# Employee Data Analysis Using SQL

## Project Overview
This project focuses on analyzing employee data using SQL queries to extract meaningful insights and practice data analysis techniques.

## Files Included
- `employee_data.csv` – Employee dataset used for analysis.
- `employee_data_analysis.sql` – SQL queries written to analyze the dataset.

## Tools Used
- SQL
- MySQL
- MySQL Workbench (if used)

## Project Objectives
- Analyze employee data using SQL.
- Filter and sort records.
- Perform data aggregation.
- Generate insights from employee information.

## How to Run the Project
1. Download the repository files.
2. Import `employee_data.csv` into your SQL database.
3. Open `employee_data_analysis.sql` in your SQL editor.
4. Execute the queries to perform the analysis.

## Conclusion
This project demonstrates practical SQL querying and data analysis skills through employee data exploration.
## SQL Analysis and Results

The project uses SQL queries to explore employee data and answer 10 business questions.

### Key Analysis Areas
- Employee records and department-wise filtering
- Salary filtering and salary-based sorting
- Employee count by department
- Average salary by department and job role
- Highest salary in each department
- Departments with more than two employees
- Employees with more than five years of experience

### SQL Concepts Practiced
`SELECT`, `WHERE`, `ORDER BY`, `COUNT()`, `AVG()`, `MAX()`, `GROUP BY`, and `HAVING`.

### Outcome
Successfully executed all 10 SQL queries in MySQL Workbench to practice employee data analysis and retrieve insights from the dataset.
